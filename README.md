# Autonomous RC Car Research

Undergraduate research project exploring autonomous driving using computer vision, deep learning, and embedded computing.

## Project Overview

As a Summer Undergraduate Research Fellow at Randolph-Macon College, I worked on developing an autonomous RC car using a Raspberry Pi and the DonkeyCar framework. The project explored approaches to autonomous navigation using machine vision and convolutional neural network (CNN)-based imitation learning.

The work involved both software and physical hardware, requiring experimentation with data collection, model training, vehicle calibration, and autonomous driving performance.

## What I Worked On

- Configured a Raspberry Pi-based RC car using the DonkeyCar framework
- Set up and worked with a simulated autonomous-driving environment
- Collected and cleaned image data for model training
- Trained and evaluated CNN-based models for autonomous driving
- Explored machine-vision and imitation-learning approaches
- Calibrated steering and throttle behavior
- Tested autonomous driving performance and iteratively adjusted the system
- Debugged issues involving both software and physical hardware
- Documented experimental results and research findings

## Technologies & Skills

**Programming:** Python  
**Machine Learning:** Deep Learning, CNNs, Imitation Learning  
**Computer Vision:** Image-based autonomous navigation  
**Hardware:** Raspberry Pi, RC vehicle hardware  
**Tools & Platforms:** DonkeyCar, Linux  
**Research:** Data Collection, Data Cleaning, Model Training, Model Evaluation, Experimental Testing

## Research Experience

This project was completed through Randolph-Macon College's Summer Undergraduate Research Fellowship (SURF) program. The experience involved integrating software, machine-learning models, and physical hardware into an experimental autonomous-driving system and presenting the research at the SURF Research Symposium.

## Key Takeaways

This project gave me hands-on experience working across the full machine-learning development process, from collecting and preparing data to training models and evaluating their behavior on a physical system. It also strengthened my experience debugging systems where machine learning, software, and hardware interact.
